```markdown
# ESP8266 Wi-Fi Access Point with Client Info Display

## Описание

Этот проект создает точку доступа Wi-Fi на базе ESP8266, которая отображает страницу с информацией о подключенных клиентах. При подключении клиент получает страницу с анимацией и сообщением, а также информацию о своем IP и MAC адресах. Данные о каждом подключенном клиенте выводятся в последовательный монитор.

## Функциональность

- Создание открытой точки доступа Wi-Fi.
- Отображение HTML-страницы с анимацией и информацией о подключенном клиенте.
- Автоматический переход в полноэкранный режим (в зависимости от браузера).
- Вывод IP и MAC адресов всех подключенных клиентов в последовательный монитор.
- Возможность подключения до 10 клиентов.

## Установка

1. Убедитесь, что у вас установлен [Arduino IDE](https://www.arduino.cc/en/software).
2. Установите библиотеку ESP8266 в Arduino IDE:
   - Откройте Arduino IDE.
   - Перейдите в **Файл** -> **Настройки**.
   - В поле "Дополнительные URL-адреса менеджера плат" добавьте:
     ```
     http://arduino.esp8266.com/stable/package_esp8266com_index.json
     ```
   - Перейдите в **Инструменты** -> **Плата** -> **Менеджер плат** и установите **ESP8266**.
3. Скачайте или клонируйте этот репозиторий на свой компьютер.
4. Откройте файл `.ino` в Arduino IDE.
5. Подключите ESP8266 к компьютеру и выберите соответствующую плату в **Инструменты** -> **Плата**.
6. Загрузите программу на ESP8266.

## Использование

1. После загрузки кода, ESP8266 создаст точку доступа с именем `100%-Free-WiFi`.
2. Подключитесь к этой сети с помощью вашего устройства (ноутбук, смартфон и т.д.).
3. Откройте веб-браузер и перейдите по адресу `http://192.168.4.1`.
4. Вы увидите страницу с анимацией установки и информацией о вашем IP и MAC адресах.
5. В последовательном мониторе Arduino IDE вы сможете увидеть IP и MAC адреса всех подключенных клиентов.

## Примечания

- Браузеры могут блокировать автоматический переход в полноэкранный режим без взаимодействия пользователя.
- Максимальное количество одновременно подключенных клиентов ограничено 10. Вы можете изменить это значение, изменив размер массива в коде.
```
